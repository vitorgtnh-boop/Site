# Site institucional — fornecedor para licitações

Site estático (HTML/CSS/JS, sem dependências) para apresentar a empresa a órgãos públicos.

## Como editar
Todo o conteúdo fica em **`js/empresa.js`**: razão social, CNPJ, endereço, contatos,
**ramos de atuação (CNAEs)**, documentação de habilitação e portais de compras.
Substitua os campos marcados com `PREENCHER` pelos dados do Cartão CNPJ.

## Visualizar
Abra `index.html` no navegador.

## Publicar grátis
GitHub Pages: Settings → Pages → Branch `main` / pasta raiz.
